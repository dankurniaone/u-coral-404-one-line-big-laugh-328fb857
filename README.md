Entry for the make.fun bounty: https://make.fun/competitions/u-coral-404-one-line-big-laugh-328fb857

One funny line, 200 characters or fewer, that lands entirely on its own. The program writes it to `/output/entry.txt` and self-checks the 1–200 character gate before writing.

## The line

> The Roomba mapped my apartment, found the spot where I cry, and now vacuums around it out of respect.

## Run

```sh
python3 main.py
```
